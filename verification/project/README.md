## 侧栏展开与工具栏修正 · 2026-10-18

原实现展开时立即通过 `display:none` 移除恢复图标和占位，标题在点击同帧从 x118 移至 x77，产生 41px 左跳；随后 Grid 列宽过渡又将标题向右移动。逐帧变化还会触发画布尺寸观察器重排。

现将恢复图标保持为常驻节点，通过透明度过渡退出，标题同步平移；Grid 一次更新到目标布局，对话面板和画布通过 Web Animations 的平移过渡到新位置。新点击会从当前可见位置反向，不累积动画；面板收放保留画布视角。键盘与减少动态效果仍受支持。

实测两种桌面宽度，点击同帧标题位置偏移为 0，约 16.7ms 后开始移动，画布每次仅发生一次尺寸变化。数据见 `motion-report.json`；修正前采样保留于 `sidebar-debug/before.json`。

右上工具栏依据原站实时计算样式与用户截图校正。参考数据为 `reference/project/toolbar.json`，用户提供的局部参考图为 `reference/project/toolbar.png`。按钮为 32×32px、10px 圆角、`#181818` 底色；SVG 盒为 18×24px，按钮间隔 4px，分隔线为 2×12px、`#3f3f3f`。

`sidebar-motion.mp4` 是实际渲染录屏，包含往返、中途反向、快速点击及资产栏恢复，已在内置浏览器播放到结束，无媒体或控制台错误，见 `sidebar-playback.json`。4 倍 CPU 降速下的八次往返也未出现标题瞬移或反向跳动，见 `sidebar-debug/cpu-stress.json`。重新录制：`node scripts/record-project.cjs`。
