# 登录态首页复刻检查

用户登录后，Meshy 首页的关键布局来自已认证的原站页面：左侧固定 64px rail，主内容通过 `--sidebar-w` 向右偏移，标题包含「嗨，yaohermione！」。本检查使用原站登录态读取到的几何数据，验证本地页面的结构、图片和无外部请求状态。

运行：

```sh
npm run verify:logged
```

检查了 1094×950 与 1588×950 两个浏览器宽度。两者都要求：左侧 rail 宽度为 64px；标题、生成框、社区标题和卡片网格的位置与原站登录态相同；20 张社区卡片存在，图片全部加载；页面没有横向溢出、脚本错误或外部请求；生成按钮保持登录态中的禁用灰色样式。

截图与 JSON 结果在本目录：[登录态检查 JSON](logged-report.json)、[1094px 本地页面](logged-local-1094.png)、[1588px 本地页面](logged-local-1588.png)。
