- 300 张位图全部核对真实格式、尺寸、透明通道、SHA-256 和字节数；单张文件没有变大。
- 297 张 WebP、3 张兼容性 PNG；SVG、ICO 和字体保持原格式。
- 所有资源清单路径和字节数与磁盘文件一致，远程来源 URL 保留。
- 压缩工具重复运行不再编码，累计体积保持一致。
- 构建通过；14 个页面状态无 HTTP 失败或 JavaScript 异常，关键卡片位置与尺寸和优化前一致。
- Redesign 1 现有专项测试的 36 项检查通过。
- Redesign 2 现有测试对项目侧栏数量的预期已过时，项目页现有测试对素材来源 / 数量的预期也已过时；两项失败在未优化的基准版本同样复现，并非本次图片迁移引入。

## 体积
